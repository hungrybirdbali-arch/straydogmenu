# Adding images in the next design pass

Create an `images` folder beside index.html.

Recommended:
- hero.jpg — 1600 × 1000 px or larger
- logo.svg — transparent vector logo
- menu/item-name.jpg — optional menu item photos

For spreadsheet-driven item photos, add an `IMAGE` column to the relevant sheet.
Use a publicly accessible image URL in that cell.
